Sobre o Projeto

O Controle de Manutenção de Frotas é um sistema desenvolvido para auxiliar empresas no gerenciamento da manutenção de veículos da frota, permitindo maior controle sobre revisões preventivas, ordens de serviço e histórico de manutenção.

O sistema possui uma lógica central baseada em planos de manutenção, onde cada veículo possui revisões programadas por:
Data
Quilometragem
Quando o limite configurado é atingido, o sistema gera alertas automáticos indicando a necessidade de manutenção.

Objetivos:
Reduzir falhas mecânicas
Melhorar o controle logístico da frota
Automatizar alertas de revisão
Organizar históricos de manutenção
Facilitar o gerenciamento de custos operacionais
